# Структура Git
- `main` - главная ветка для релизов.
- `development` - ветка для разработки и слияния фичей.
- `feature/*` - ветки для нового функционала.

![Git Structure](https://git-scm.com/images/branching-illustration@2x.png)

## Описание
Проект представляет собой клиент-серверное приложение на базе Qt6 C++.
Сервер обрабатывает запросы клиентов:
- Шифр Виженера
- Хэширование SHA-512
- Метод деления пополам
- Поиск кратчайшего пути в графе

Клиент обеспечивает оконный интерфейс для взаимодействия с этими функциями.

Ветки созданы согласно требованиям.
