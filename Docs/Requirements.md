# Спецификация требований (Requirements)

## 1. Введение
Проект представляет собой клиент-серверное приложение, предназначенное для демонстрации базовых математических и криптографических алгоритмов, а также принципов сетевого взаимодействия и ролевой модели доступа.

## 2. Функциональные требования
- **F1:** Сервер должен обрабатывать одновременные подключения нескольких клиентов.
- **F2:** Клиент должен предоставлять графический интерфейс пользователя (GUI) для ввода данных.
- **F3:** Должна поддерживаться аутентификация и регистрация пользователей (ролевая модель: guest, user, admin).
- **F4:** Реализация алгоритмов:
  - Шифр Виженера
  - Хэширование SHA-512
  - Метод деления пополам для нахождения корня уравнения
  - Поиск кратчайшего пути в графе (алгоритм Дейкстры)
- **F5:** Администратор должен иметь возможность менять роли пользователей через GUI.

## 3. Нефункциональные требования
- **NF1:** Приложение должно быть написано на C++ с использованием Qt6.
- **NF2:** Клиент и база данных сервера должны быть реализованы с использованием паттерна Singleton.
- **NF3:** Проект должен собираться с помощью CMake.
- **NF4:** Должна быть обеспечена возможность сборки и запуска сервера через Docker (docker-compose).

## 4. Требования к базе данных
- **DB1:** Использовать SQLite.
- **DB2:** Хранить пароли в виде хэшей SHA-256.
