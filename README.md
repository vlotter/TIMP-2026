# TIMP 2026 Project

Клиент-серверное приложение на C++ Qt6.
Реализовано:
- Шифр Виженера
- Хэширование SHA-512
- Метод деления пополам
- Кратчайший путь в графе

## Сборка
Проект использует CMake 3.28+.
В корне проекта выполните:
```bash
mkdir build
cd build
cmake ..
make
```

## Запуск
Для сервера есть Docker:
```bash
docker-compose up --build
```
Клиент запускается локально (требуется Qt6):
```bash
./build/Client/Client
```
